# SpaceLab - Hamdy Mohamed

SpaceLab is a modern web project designed to provide a smooth and efficient user experience using the latest web technologies.

## Features

- 🌐 **Arabic & English Languages**  
  Seamlessly switch between languages without reloading the page.

- ⚡ **Dynamic Translation without Reload**  
  Real-time content updates powered by React for smooth performance.

- 🛠️ **High Performance with React Compiler**  
  Minimizes re-rendering to ensure the best possible performance.

- 🎨 **Beautiful & Modern Styles**  
  Engaging user interface with a clean and elegant design.

- 📸 **High-Quality Images**  
  Uses **WebP** format for smaller file sizes without losing quality, leveraging the Pexels library for perfect visuals.

## Tech Stack

- React.js
- JavaScript (ES6+)
- CSS / SCSS
- WebP images
- Pexels API
